# Supply Tracking C++ System

Sistema de controle e rastreamento de insumos em memória desenvolvido em C++17 moderno.

## 🚀 Como Compilar e Executar

Usando o `g++` via terminal do VS Code:

```bash
g++ -std=c++17 src/ItemInsumo.cpp src/GerenciadorInsumos.cpp src/main.cpp -Iinclude -o sistema_insumos
./sistema_insumos
